# nowshad7.github.io

Personal portfolio of **Robiul Hasan Nowshad**, Senior Software Engineer. Live at [nowshad7.github.io](https://nowshad7.github.io/).

It's a static site with no build step:

- `index.html` holds the page content (sections, projects, experience)
- `assets/css/style.css` holds the design tokens and the light/dark themes
- `assets/js/main.js` runs the animations: the hero network canvas, scroll reveals, counters, code typing, tilt cards and the theme switch
- `Documents/CV_Nowshad.pdf` is the downloadable CV

To preview locally, run `python3 -m http.server` and open http://localhost:8000.
